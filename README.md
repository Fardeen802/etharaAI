# Ethara AI – Team Task Manager

## Features
- Auth (JWT + HTTP-only cookies)
- Role-based access (Admin / Member)
- Projects & team management
- Task assignment & status tracking
- Dashboard analytics

## Tech Stack
React, Node.js, Express, MongoDB, Railway

## Live URLs
Frontend: https://etharaai.up.railway.app  
Backend: https://etharaai-production.up.railway.app
